# azhen blue mg video

## 首次安装与换角色

在安装对话完成复制后立即执行本节。手动复制文件夹的用户首次调用时执行。先运行本 Skill 目录下的 `python3 scripts/profile.py status`。已有称呼且参考图可读就沿用。已有信息在当前消息或附件里时直接使用，只问缺项。两项都缺时，第一条回复直接问：

```text
以后希望我怎么称呼你？再发我一张你的 IP 三视图，包含正面、侧面和背面。以后视频里的头像、角色插图和片尾都会用这个形象。
```

先看图，确认三个角度属于同一角色。三张分开的图片按正、侧、背并排拼成一张，保留比例和原始角色颜色。缺角度、无法识别或附件不可读时只补问缺的内容。收到后用实际称呼和图片路径运行 `python3 scripts/profile.py set "称呼" "/参考图绝对路径"`。只做安装时，回告设置完成即可。用户后来换称呼时用原参考图重新设置，换 IP 时改用新图。将已有的可选偏好沿用到新配置前先判断是否仍适合此角色。

配置保存在接收者自己的 `~/.config/blue-mg-video/`（设置了 XDG_CONFIG_HOME 时使用该目录）。称呼用于对话和默认片尾。对方指定公开署名或不同片尾时，将完整片尾文案写入 profile.json 的可选字段 `outro`。频道名、标志、配音音色、背景音乐和平台用语按需设置。分享时发原始安装包。

## 第一次做片

1. 询问要做的画幅和字体，默认竖版黑体。可以多选横版、竖版、黑体、文楷。按题目核实来源，把开头问题、核心观点、数字出处、逐屏口播和图形如何变形写进提纲。确认提纲后制作。
2. 将本 Skill 的 `template/` 复制进用户的项目目录。所有命令在对应工程运行，配置脚本从 Skill 的实际安装目录调用。项目内放音频、插图、预览、成片和交付说明。
3. 从 status 返回的 reference 找到角色目录。在这一目录首次备齐三个派生文件。根据三视图正面裁出方形透明头肩像 `ip_face_wide.png` 与透明全身立绘 `ip_sticker.png`。原图裁不净时，以三视图为参考生成，保留脸型、比例、服装、轮廓和配件。在最终头肩图上测量嘴中心，除以图宽和图高得到 x、y；写入 `mouth.json`，例如 `{"x":0.51,"y":0.63,"s":0.7}`，数值按实图调整。无可见嘴部写 `null`。同一角色后续项目复用。
4. 运行 `python3 "/Skill绝对路径/scripts/profile.py" apply "/单片工程绝对路径"`。模板由此获得当前角色、片尾称呼和口型参数。所有角色插图只引用本次工程中的 reference 图片。
5. 按 [制作流程](references/production.md) 完成配音、插图、混音、场景和渲染；编写场景时查 [引擎接口](references/engine.md)。模板的两屏短例用于验证角色和蓝色主题，正式内容根据提纲重写。

## 画面与验收

- 纸色底、墨色字，主蓝 `#2463D4` 给标题关键词、主图形、头像描边、片尾按钮和转场。浅蓝 `#E8F1FF` 铺标签，深蓝 `#174FAF` 写浅底小字，亮蓝 `#84B8FF` 用在深色屏。角色保留自身配色。数字可用 Fraunces 斜体，黑体优先 MiSans；文楷版需在接收者电脑安装霞鹜文楷。
- 标题逐字入场，短标题一行，横版在语义边界用 `|` 分两行。竖版左右界 x=110、970，横版用左栏标题与右栏内容框。正文左对齐，组内距 24、组间距 40、段间距 64。标签有边框，插图透明底。
- 每屏一个主角。先出现元素，再在口播点名时高亮、变形或计数。把上一屏末态作为下一屏初态。镜头停稳，在信息变化时用约 0.6 秒推到位；按叙事混用擦除、横推、圆形揭示等转场，长片至少用五种、四种版式。
- 字幕用黑底白字胶囊，头像在右下；片尾用用户立绘与配置文案；点赞、推荐和转发三个动作按发布平台调整。抽查发声和停顿两帧，看嘴有没有偏。逐画幅检查开头、转场、片尾，确保署名完整可读。
- 提纲写明预计片长。首次交付使用 preview 命令，从开头截取 15 秒，输出带口播和字幕的 1080p、30fps 样片。全片短于 15 秒时按实际时长交付。用户确认样片的画风、口播和节奏后，再完成后续场景并逐个导出所选的 2K 50fps 完整版本。文件名含片名、画幅、字体、版本；交付说明列明数字来源、素材、音色、异常与处理。
