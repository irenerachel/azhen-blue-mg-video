# azhen blue mg video

用自己的 IP 角色制作蓝色动态图形口播视频。首次安装时填写称呼，提供同一角色的正面、侧面和背面三视图。后续视频沿用这个角色制作头像、插图和片尾。

## 安装

[下载 Skill 分享包](./azhen-blue-mg-video.zip)，把 ZIP 发给 Codex，并附上这句话：

```text
请安装 azhen-blue-mg-video。安装完成后，带我设置称呼和 IP 三视图。
```

也可以解压后在该目录运行 `python3 install.py`，按终端提示完成设置。[完整安装说明](./安装说明.txt)

## 制作视频

确认提纲后，首次预览提供开头 15 秒的 1080p、30fps 样片。短于 15 秒的视频按实际片长预览。样片确认后再制作完整版本，支持横版、竖版、黑体和文楷，以及 2K、50fps 导出。

[查看 Skill 与制作流程](./azhen-blue-mg-video/SKILL.md)
